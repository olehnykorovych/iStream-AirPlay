iStream - AirPlay screen mirroring for Windows
==============================================

QUICK START
1. Run iStream.exe (keep it next to the "engine" folder).
   If Windows SmartScreen warns: More info -> Run anyway (the app is not code-signed).
2. If a banner says the firewall is blocking iStream, click "Fix firewall".
3. On your iPhone: Control Center -> Screen Mirroring -> iStream.
   The phone and the PC must be on the same network.

SHORTCUTS
  Ctrl+Alt+F   toggle fullscreen
  Ctrl+Alt+R   rotate 90 degrees

SZYBKI START (PL)
1. Uruchom iStream.exe (musi leżeć obok folderu "engine").
   Jeśli SmartScreen ostrzeże: Więcej informacji -> Uruchom mimo to.
2. Jeśli pojawi się pasek zapory, kliknij "Fix firewall".
3. Na iPhonie: Centrum sterowania -> Klonowanie ekranu -> iStream.
   Język polski: Settings -> Language -> Polski.
